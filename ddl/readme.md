Some useful information:

- [PKG_SAMPLE](package/pkg_sample.pks) is the official sample package, which is fully documented using the __ora* CODEDOC syntax (OCDs)__. Read [here](https://github.com/yerba1704/ocd/blob/main/doc/ocds.md) for more information.

- [APEX_CSS](package/apex_css.pks) is the original package from Oracle APEX and can be used for comparison.

- [APEX_CSS_MODIFIED](package/apex_css_modified.pks) is the original Oracle APEX package, reformatted in the style of __ora* CODEDOC syntax (OCDs)__.
