The package publishes one subtype, one constant, one user-defined exception, three collection types, one record type, one procedure and one function. The complete package specification is reproduced in PKG_SAMPLE Package Specification.

Security Model

PKG_SAMPLE is defined with AUTHID CURRENT_USER. The package therefore runs with invoker's rights: it executes with the privileges and in the schema context of the user who calls it, not with those of the user who owns and defined the package. External references in the package body are resolved in the schema of the current user, and roles are enabled during the call.

Syntax

subtype s_counter is naturaln;

Usage Notes

  • The base type NATURALN constrains the value to integers greater than or equal to zero.
  • The NOT NULL constraint is inherited from NATURALN; every variable or constant declared with this subtype must be initialized at declaration.

T_NUMBER_AA Associative Array Type

This is an example of an associative array description. It was formerly called PL/SQL table or index-by table.

Syntax

type t_number_aa is table of number index by varchar2(64 char);

Usage Notes

  • Elements are of data type NUMBER and are indexed by a string key of up to 64 characters.
  • The collection is sparse and unbounded; elements need not be allocated with EXTEND.
  • An associative array cannot be stored in a database column; it exists only for the duration of the session.

T_NUMBER_VA Varray Type

This is an example of a varray (variable-size array) description.

Syntax

type t_number_va is varray(5) of number;

Usage Notes

  • The collection is dense and holds a maximum of five elements of data type NUMBER.
  • The collection must be initialized with its constructor and extended with EXTEND before elements can be assigned.
  • Subscripts are consecutive integers starting with 1.

T_NUMBER_NT Nested Table Type

This is an example of a nested table description.

Syntax

type t_number_nt is table of number;

Usage Notes

  • The collection is unbounded and may become sparse when elements are deleted.
  • The collection must be initialized with its constructor and extended with EXTEND before elements can be assigned.
  • Nested tables support the collection set operators, for example MULTISET UNION.

Function for square a number.
