1.1 Security Model

PKG_SAMPLE is an invoker's rights package, declared with AUTHID CURRENT_USER. At run time, privilege checking and name resolution follow Oracle's invoker's rights rules.

create or replace package pkg_sample authid current_user

1.6.2 F_SQUARE Function

Function for square a number. The return value is the result of multiplying the parameter by itself.

The square of any non-zero real number, whether positive or negative, is always a positive number.

Syntax

function f_square(i_value number default 3) return number;

Parameters

ParameterMode / TypeDefaultDescription
i_valueIN NUMBER3A numeric value.

Return Value

A NUMBER: the result of multiplying i_value by itself.

Examples

Examples from the specification comments. A package body is required to execute these calls.

select pkg_sample.f_square from dual;
select pkg_sample.f_square(4)
  from dual;
begin
  dbms_output.put_line( 'square of 2 is '||f_square(2) );
end;
Usage Note

The original PL/SQL example uses an unqualified f_square(2) call. Outside the package, use pkg_sample.f_square(2) and enable your client's DBMS_OUTPUT display.
